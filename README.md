# Lens · Amazon Product Intelligence

An interactive dashboard of 1,348 cleaned Amazon product listings, created by Yuvraj Verma for the Pine Labs data science assessment.

Open `index.html` in a modern browser, or visit the published GitHub Pages site. The dashboard includes its own data, styles and chart library and also works offline.

Explore category comparisons, prices, discounts, ratings and rating counts. Filter the dashboard, search products and export the current selection as CSV. These are product listings, not measured sales or revenue.

The published data contains product IDs, names, categories, prices, discounts, ratings and rating counts. Reviewer names, customer IDs, review IDs and review text are excluded.

## Hosting

This folder is a complete static GitHub Pages site. Publish the repository root from the `main` branch. No build step or dependencies are required.
